## Показатели всегда под рукой

Следите за тремя сервисами на одной панели во время работы с кодом и моделями, а важные значения оставляйте на рабочем столе.

- **Компактный плавающий индикатор**: два процента показывают остаток лимита на 5 часов и на неделю. Индикатор можно перетаскивать, открывать подробности двойным щелчком и менять его размер (пять вариантов).
- **Отдельные плавающие окна**: для каждого сервиса можно отдельно включить или скрыть окно, переместить его и изменить размер. Подключённые сервисы продолжают обновляться и при скрытых окнах.
- **Локальная история**: графики за 7 и 30 дней, хранение в течение 90 дней. Пропущенные наблюдения не подменяются вымышленными значениями.
- **Настраиваемый вид**: светлая, тёмная или системная тема, три размера шрифта и постоянная боковая навигация.
- **Обновление и откат**: скачайте и проверьте пакет внутри приложения, подтвердите перезапуск; предыдущая версия сохраняется для отката.

## Поддерживаемые данные

| Сервис | Что показывает приложение | Подключение |
| --- | --- | --- |
| **ChatGPT / Codex** | Общий остаток лимита Codex / ChatGPT Work, время сброса и доступные сбросы | Вход в Codex на этом компьютере |
| **DeepSeek** | Доступный, пополненный и подарочный баланс по валютам | API Key или локальный вход в DeepSeek Harness |
| **OpenAI API** | Токены за сегодня и месяц, входные/выходные/кэшированные входные токены и число запросов для API Key ID | Обычный API Key; для истории также нужны Admin API Key и соответствующий Key ID |

Данные ChatGPT относятся к лимиту Codex / ChatGPT Work и не охватывают все ограничения сообщений обычного чата. Статистика OpenAI берётся из официального endpoint `usage/completions`. Кэшированные входные токены уже входят в число входных и не суммируются повторно.

## Быстрый старт

**Требования: Windows 10 / 11 x64 и .NET Framework 4.8. Интерфейс приложения пока доступен на китайском языке.** Для работы не нужны Python, Node и .NET SDK.

1. [Скачайте ZIP для Windows](https://github.com/Ricki0613/TokenMonitor/releases/download/v3.2.1/TokenMonitor-v3.2.1-windows-x64.zip) и полностью распакуйте его. Выбирайте архив с программой, а не автоматически созданный GitHub архив `Source code`.
2. Запустите **Install.cmd** и выберите папки программы и данных. Установщик создаст ярлыки на рабочем столе и в меню «Пуск». Можно также запустить распакованный `TokenMonitor.exe` напрямую.
3. Подключите нужные сервисы через **连接设置** («Настройки подключения») на карточках, затем включите плавающие окна или индикатор.

По умолчанию обновление данных происходит каждые **30 секунд**. На панели можно выбрать 15 / 30 / 60 / 120 секунд или обновить вручную. Закрытие главного окна сворачивает приложение в область уведомлений. Двойной щелчок по значку откроет окно; через меню значка можно полностью выйти.

[Установка и устранение неполадок](docs/START_HERE.zh-CN.md) · [Подробное руководство](docs/USER_GUIDE.zh-CN.md) (оба документа на китайском)

### DeepSeek: API Key или Harness

Введите API Key в разделе **DeepSeek 密钥** либо войдите в Harness под тем же пользователем Windows и выберите **DeepSeek 密钥 → DeepSeek 余额来源 → DeepSeek Harness 登录账户**. Сохраните выбор; оставлять Harness открытым не нужно.

Режим Harness объединяет пополненный и подарочный кошельки отдельно по каждой валюте. Учётные данные считываются по мере необходимости из стандартного локального расположения и не копируются в Token Monitor. Источник можно переключить на API Key. Пользовательские каталоги Harness и неофициальные серверы не поддерживаются. См. [правила работы с учётными данными](SECURITY.md).

### OpenAI: проверка ключа и доступ к истории

Сначала проверьте обычный API Key, затем укажите организационный **Admin API Key** и соответствующий **API Key ID** (`key_…`). Успешная проверка обычного ключа сама по себе не даёт доступ к истории использования. Если настройка не завершена, приложение подскажет следующий шаг, а не покажет нулевое использование.

## История, обновления и локальные данные

### Графики за 7 и 30 дней

На графиках используется пекинское время (UTC+8). ChatGPT и DeepSeek сохраняют последнее успешно полученное значение за каждые 15 минут. История связана с локальным источником; смена учётной записи влияет на график.

Дневное использование OpenAI хранится отдельно по хешу Key ID. При каждом запросе полученные показатели текущего месяца корректируются. Для прошлых месяцев остаются только ранее собранные данные; сегодняшний показатель предварительный.

**Изменение баланса не равно расходу.** Пополнения, подарочные средства и возвраты также меняют баланс DeepSeek.

### Обновление внутри приложения

В разделе **关于软件** («О программе») можно проверить наличие обновлений, прочитать описание и скачать пакет. Перед подтверждением перезапуска и установки приложение проверяет SHA-256 и версию исполняемого файла. Настройки, учётные данные и история сохраняются; на той же странице можно вернуться к предыдущей версии.

Стабильные релизы проверяются при запуске и каждые шесть часов после успешной проверки. Ошибки сети и ограничения GitHub не останавливают мониторинг; ссылка для ручной загрузки остаётся доступной. С v3.1.0 и более ранних версий первое обновление требуется установить вручную.

[Список релизов](https://github.com/Ricki0613/TokenMonitor/releases) · [История изменений](CHANGELOG.md)

### Данные остаются на компьютере

Для обычной работы и сохранения ключей не нужны права администратора. Каталог по умолчанию: `%LOCALAPPDATA%\TokenMonitor`. В разделе **数据目录** можно выбрать пустую папку с правом записи: настройки, учётные данные и история копируются и проверяются до переключения. Исходная папка сохраняется как резервная копия.

- Ключи DeepSeek и OpenAI шифруются Windows DPAPI для текущего пользователя.
- Учётные данные Harness читаются по мере необходимости и отправляются только официальному сервису DeepSeek.
- Проверка использования не выполняет запросов к моделям. Использование официального сброса лимита требует отдельного подтверждения.
- Проверка обновлений не отправляет GitHub настройки, учётные данные или сведения об использовании аккаунтов.

Подробности — в [SECURITY.md](SECURITY.md). Данные провайдеров могут поступать с задержкой. Автозапуск не настроен, опубликованные исполняемые файлы пока не имеют цифровой подписи.
