# v3.0.1 — 完整深色外观与分页设置

发布日期：2026-10-25

- 修复深色模式下 Windows 标题栏仍为白色的问题，标题栏随浅色、深色及系统主题切换；同时去除标题中的重复软件名。
- 修复 ChatGPT 悬浮球右键菜单白底白字，统一菜单背景、文字、选中状态、提示及滚动条的主题颜色。
- 设置改为主窗口内的侧边导航页面：外观设置、DeepSeek 密钥、OpenAI 密钥、数据目录、关于软件。返回概览不再关闭独立弹窗。
- 主题、悬浮球大小、自动刷新间隔选择后立即生效；主题与大小自动保存。数据目录在选择并迁移成功后立即切换。
- 只有密钥页面显示“保存密钥设置”。切换页面保留待保存输入，返回概览清除未提交的密钥输入；修改外观不会提交另一页的密钥。
- 检查更新、发布页及源码入口统一放入“关于软件”，托盘更新入口直接打开该页面。
- 统一称为“ChatGPT 悬浮球”，明确展示 Codex 与 ChatGPT Work 共用的额度。

保留 v3.0.0 发布记录，不覆盖原安装包；v3.0.0 用户可通过更新检查发现此修复版。升级保留账户设置与数据目录。

验证使用模拟账户数据，不发起真实账户请求，也不消耗额度重置次数。

## 界面展示

设置在主窗口内按外观、DeepSeek 密钥、OpenAI 密钥、数据目录和关于软件分类切换。主题、悬浮球大小及刷新间隔即时生效；密钥需点击保存。更新检查与发布页位于关于软件。
