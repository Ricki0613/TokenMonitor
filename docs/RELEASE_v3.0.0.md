# v3.0.0 — 全新控制中心与 Codex 额度悬浮球

发布日期：2026-10-25

- 全新正式桌面主界面，支持系统标题栏、最小化、最大化和窗口缩放，集中展示三项服务状态。
- Codex 详情窗可一键收为悬浮球：上方青色短弧代表 5 小时剩余额度，下方紫色长弧代表每周剩余额度，两项均显示百分比。
- 双击悬浮球展开详情，拖动改变位置；右键可刷新、打开控制中心、设置大小或隐藏。隐藏会暂停该服务刷新。
- 设置提供 80%、100%、125%、150%、200% 五档尺寸，记住模式、大小和独立位置。100% 为 76 个逻辑像素，约 2 cm，实际大小受显示器和系统缩放影响。
- 未返回的窗口显示破折号；请求失败保留旧数据、淡化弧线并显示警告，悬停查看同步时间。不会把其他额度池冒充为 Codex。
- 更新青紫双色 Token Monitor 图形标志，统一主界面、悬浮球、程序和托盘图标。
- 保留 DeepSeek API / Harness 余额、OpenAI API 用量、主题、更新检查、数据目录迁移和原有账户配置。

升级：退出旧版，运行安装包内 Install.cmd 选择原安装目录，或覆盖程序文件。保留原数据目录，无需重新输入已保存的密钥。已有用户启动后仍可使用原详情窗，在控制中心点击“Codex · 悬浮球”即可切换。

验证：离线功能测试、UI 模拟数据测试及安装包完整性 / 自定义路径安装测试。测试不调用真实账户，也不消耗额度重置次数。

## 界面展示

正式桌面控制中心与可展开的额度悬浮球。上方青色短弧显示 5 小时剩余百分比，下方紫色长弧显示每周剩余百分比。支持五档大小、拖动、双击展开和右键操作。
