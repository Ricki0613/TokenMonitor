# Token Monitor v2.1.0

2026-10-11

**需要应用内更新检测，请选择 v2.1.0 及以后版本。v2.0.0 及更早版本需先手动升级一次。**

## 新增

- 启动时自动检查本项目 GitHub 最新正式 Release，成功后每 6 小时复查。
- 控制面板显示可用新版本，托盘通知提醒；同一版本在本次运行中只通知一次。
- 控制面板和托盘支持手动检查，两次请求至少间隔 1 分钟。
- “下载更新”打开对应 GitHub 发布页；用户下载并安装，不自动覆盖程序。
- 超时、断网和 GitHub 限流会显示提示，1 小时后自动重试，不影响用量监控；失败时保留已发现的新版提示。
- 按数字比较正式版本，排除草稿和预发布，不把旧版或相同版本当作更新。
- 检测只访问公开 Release 接口，不发送配置、密钥或账户用量。

## 升级

下载 `TokenMonitor-v2.1.0-windows-x64.zip`，全部解压。从旧程序托盘退出后，运行新包的 `Install.cmd` 并选择原安装目录，或覆盖原目录中的运行文件。保留现有数据目录、配置和密钥。

## 后续发布约定

使用递增的 `v主版本.次版本.修订号`（例如 `v2.2.0`），附上 Windows ZIP 并发布正式 Release，标记为 **Latest**。仅推送源码或标签、保存草稿、发布预览版不会提示更新。

## 验证

通过 65 项离线自测、60 项界面检查和 6 项安装包检查。更新测试覆盖版本比较、远端响应校验、请求隔离、限流/网络失败及新版界面提示，使用模拟数据，不消耗模型 Token。
