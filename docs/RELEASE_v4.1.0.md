# Token Monitor v4.1.0

2026-11-24 发布。

- 悬浮球、进度条、开关与按钮统一采用 Logo 青色 `#5EEAD4` 和紫色 `#A99CFF`；深色底色采用 `#171D2B`。文字与错误提示保留清晰对比。
- 浮窗与悬浮球右键菜单仅保留控制中心、隐藏、立即刷新，以及适用时的双向显示切换。
- ChatGPT 与 Kimi 订阅支持左键双击在浮窗和悬浮球之间双向切换。
- 浮窗移除拖动缩放边框，按字号与各服务实际文字宽度自动贴合，标签和数值之间至少保留 8 个逻辑像素，高度自动贴合内容；旧版保存的放大尺寸不再生效。
- 控制中心固定为 920 × 720 个逻辑像素（小屏幕不超过工作区），切换页面和字号不改变窗口尺寸；长页面保留滚动。
- 保留现有账户连接、加密密钥、历史记录和显示偏好。

使用提示：浅色／深色主题、三个字号、两种额度显示形式双击切换、右键菜单，以及各服务连接设置页面。
