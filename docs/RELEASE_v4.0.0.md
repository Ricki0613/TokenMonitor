## 新增 Kimi 订阅和 Kimi API 余额
- Kimi 订阅卡片显示剩余额度、百分比进度条和重置时间。打开桌面端「我的订阅」即可读取，支持独立浮窗和悬浮球。
- Kimi API 卡片查询国内开放平台可用余额，按接口返回展示现金和代金券明细。API Key 由 Windows 当前用户加密保存。

## 五服务主页和桌面浮窗
- 主页可按需展示 ChatGPT、DeepSeek、Kimi 订阅、Kimi API 和 OpenAI API，按勾选数量自动布局。单卡模式放大关键指标。
- 五种浮窗精简为关键数据和刷新按钮。外观设置支持 0–100% 滑杆即时调整浮窗不透明度，最低档保留 45% 实际不透明度。悬浮球跟随系统、浅色或深色主题。
- ChatGPT 显示剩余重置次数，DeepSeek 增加余额构成。统一连接设置、表单间距和窗口按钮样式。

Windows x64 用户可下载下方 ZIP，解压后运行 Install.cmd。
