# Token Monitor v1.1.0

本次新增窗口缩放、主题设置与官方 GPT 额度重置，并修复固定高度造成的底部留白。

## 新功能

- 拖动悬浮窗边缘或角落调整大小，重启后记住尺寸。
- 宽窗卡片并排、窄窗纵排与按钮换行，字号保持不变。
- 默认高度紧贴内容；顶部 **↕** 恢复贴合高度，手动缩短后可滚动。
- “设置 → 外观”支持 **浅色、深色、随系统**。
- ChatGPT 浮窗显示 **重置额度 (N)**，确认后使用官方账户的一次重置权益，与 GPT 内使用重置次数相同。超时后可确认上次结果，避免重复扣次数。

## 下载与升级

下载 **TokenMonitor-v1.1.0-windows-x64.zip**，解压后运行 `TokenMonitor.exe`。

已有 v1.0.0：先从托盘退出，用新版本的 `TokenMonitor.exe`、`TokenMonitor.exe.config`、`TokenMonitor.ico` 覆盖旧文件，保留 `data/`。已有密钥、位置和显示偏好继续使用，默认外观随系统。

Windows 10 / 11 x64，.NET Framework 4.8。GPT 需要本机安装并登录 Codex；重置额度需要 Codex 支持官方重置接口且账户具有该权益。实际可重置窗口与次数以官方结果为准。
