# Token Monitor v3.2.0

发布日期：2026-10-26

- 新增「历史趋势」：近 7 天／30 天查看 ChatGPT 剩余额度、DeepSeek 余额变化和 OpenAI 每日 tokens。记录保存在本机，保留 90 天。
- DeepSeek 按 API / Harness 来源及币种分别展示；余额变化不等于消费，充值、赠送和退款都会改变余额。
- 在「关于软件」直接下载安装包，SHA-256 与版本校验通过后确认重启更新。保留上一版，可从同页回退；配置、密钥与历史记录保留。
- 主窗口固定大小（小屏幕按工作区收敛），卡片不再随窗口拉高。刷新、设置与退出集中到右上角，滚动条更细。
- 左侧常驻账户概览、历史趋势、外观、各服务连接、数据目录与关于软件，点击即可切换。
- 新增小／中／大三档字号，默认中号，修改立即生效并保存；保留浅色、深色与随系统主题。

历史说明：额度和余额每 15 分钟保留最新成功采样，离线期间不补造数据。ChatGPT / DeepSeek 是本机来源记录，切换登录账号也会改变曲线。OpenAI 按 API Key ID 分开保存，每次查询修正已获取的本月每日值，过去月份只显示已采集数据；当天数值尚未结算。仅覆盖原有 completions 用量范围。

更新说明：首次从 v3.1.0 升到本版仍需手动安装；从本版开始支持应用内下载并重启更新。仅安装本仓库正式发布且具有 GitHub SHA-256 摘要的运行包；缺少摘要时保留手动发布页入口。替换失败会尝试恢复旧文件，备份同时保存在 updates 目录中。

验证：79 项基础测试、119 项离线界面检查；6 项安装包检查。演示图片使用模拟数据，不代表实际账户记录。
