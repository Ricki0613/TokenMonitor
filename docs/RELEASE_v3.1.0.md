发布日期：2026-10-25

- 移除大幅宣传区，概览直接展示 ChatGPT 双周期剩余额度条与官方重置时间、DeepSeek 余额、OpenAI 今日和本月 token 用量。

- 保留旧版配置、加密密钥、Harness 来源、浅深主题、悬浮球和更新检测。
