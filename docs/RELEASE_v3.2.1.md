# Token Monitor v3.2.1

发布日期：2026-10-26

- 外观设置只保留主题、界面字号和悬浮球大小；自动刷新与立即刷新统一放在账户概览。
- 悬浮球去掉「5h」和「周」标签，仅显示两行剩余额度百分比；悬停提示仍说明上方 5 小时、下方每周。
- 移除主窗口的系统标题栏和最大化入口，改用一体化圆角界面。右上角只保留最小化、关闭按钮，顶部空白区域可拖动窗口。
- 左上角使用 Token Monitor logo，替换原来的绿色圆点。
- 关闭窗口继续在托盘运行；完全退出请使用托盘菜单。保留 v3.2.0 的历史趋势、更新回退及原有配置。

验证：79 项基础测试、123 项离线界面检查、6 项安装包检查。界面示例使用模拟数据。

升级：v3.2.0 可在「关于软件」下载、校验后重启更新；也可解压 ZIP 后运行 Install.cmd，选择原安装目录。保留数据目录与上一版程序。
